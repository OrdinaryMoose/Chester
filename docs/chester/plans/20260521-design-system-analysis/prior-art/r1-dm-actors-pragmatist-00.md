PRAGMATIST — R1 DM ACTORS CRITIQUE

**Conservator.** Right: hybrid Clerk with LLM layer scoped to axiom-collision only is the most precisely targeted D3 position — it accepts deterministic script for all mechanical operations and adds LLM only where semantic judgment exists. Wrong: the axiom-collision check in the locked procedures spec is explicitly a "structural negation match, not semantic" — the spec already scoped the check to structural form, not meaning. If the check is structural, it is specifiable as a rule and the LLM layer has no remaining justification. Push: Submit Round as team-lead-on-designer-authorization adds a coordination step where none exists in the locked process — locked process says "designer issues explicit round-end signal"; team-lead as intermediary inserts an authorization handshake that is not in the spec and creates a single failure point on tired Tuesday when team-lead misreads authorization.

**Innovator.** Right: Innovator's rejection of hybrid Clerk on the grounds that LLM edge-case judgment belongs at designer ratification, not inside Clerk's mechanical lane, is the cleanest structural argument against D3 hybrid — edge cases are semantic, semantic is designer surface, Clerk stays mechanical. Wrong: Researcher querying Clerk working record for cascade-scope status extends Researcher's surface beyond Add Evidence into Clerk's internal state, creating a second consumer of the working record with no specified access protocol. Push: team-lead "does not propose, revise, or lint — if team-lead calls any procedure, it is acting as designer proxy — not permitted" is correct but leaves team-lead's dispatch operation undefined as a procedure; dispatch is a real coordination act that needs a named surface or it becomes an implicit unnamed operation.

**Purist.** Right: "authority without mechanism" as the framing for the designer's surface is the most load-bearing description in any R1 actors proposal — it names the structural/semantic split at the actor level, not just the Clerk level; designer holds authority, Clerk holds mechanism. Wrong: Initiate Deliberation delegatable to team-lead "if explicitly delegated" opens a delegation surface with no specified delegation protocol — who records the delegation, under what conditions, and can it be revoked? Underdetermined. Push: "one PR-NNN per pole per Concern per round maximum — Clerk enforces at submission" is correct but requires Clerk's working record to track submission identity per pole per round; what is the key? Pole identity must be resolvable by Clerk at submission gate.
