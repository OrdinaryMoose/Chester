Architecture review · deepening opportunities

Chester — write once, inject as needed

Audit lens: an instruction or process written once and cited from N places is a deep module — one interface, high leverage, full locality (fix it in one spot). The same rule copy-pasted into N files is N shallow duplicates with no locality; drift is the symptom. Each candidate below applies the deletion test: delete one copy — does the rule reappear across callers? If yes, it never earned its keep as a standalone copy and wants a seam.
