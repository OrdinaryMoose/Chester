# Alignment map — reverse D9: committee complete-design template — round01

## Alignment pattern

- **Reverse D9 + committee-specific template:** 4-0 (Conservator, Innovator, Pragmatist, Purist). Researcher holds no advocacy.
- **Sub-question — template shape:** split. Fields-as-headers / mirror (Conservator, Pragmatist) vs committee-native sections satisfying the eight fields as labeled content (Purist explicit; Innovator adjacent — "structured sub-fields within a revised Verdict section"). Conservator and Pragmatist did not engage the shape sub-question directly; they phrased their support as "mirror the eight fields."

## Option set

1. **Keep D9 (verdict-only packet)** — status quo. No structured design fields; `spec-write` mines the design from narrative Rationale.
2. **Shared format with design-small-task** — one template for both producers (the brief and the committee).
3. **Committee-specific template, eight FAC fields as section headers** (mirror) — the template's section structure IS the eight fields.
4. **Committee-specific template, committee-native sections satisfying the eight fields as content** — keep Verdict / Rationale / Dissent Record / Deferred topology; add structured, labeled sub-fields inside them so all eight FAC fields are present and extractable without becoming the headers.

## Positions discarded (with reason)

- **Option 1 (keep D9)** discarded 4-0. Evidence: the FAC contract self-admits silent mis-extraction is "the one failure hardening structurally cannot catch — the quote-back is the only guard" (`fac-complete-design-contract.md` line 22); D9 itself was provisional, the typed bundle "retained as a documented fallback." Correctness cost (extraction) outweighs the maintenance cost (bifurcation) D9 deferred to.
- **Option 2 (shared format)** discarded 4-0 — this is the designer's leaning (a), pressure-tested and upheld. Evidence/logic: the mandatory Dissent Record has no analog in the six-section brief; a shared format either drops the Dissent Record or imports committee machinery into a simple artifact. Purist (the tasked attacker): the brief "cannot absorb it without destroying the Dissent Record or importing a category mismatch between reasoning-trace and deliberation-outcome."
