# Rules — `design-architect-committee`

## Citation Meta-Rule

Closed-set content lives in [`schema/`](schema/). Capped files cite into `schema/` via Markdown heading anchors. Capped files never restate enumerations.

## Designer Authority

Designer holds unconditional authority — assertion, ratification, revision, withdrawal. Signals every phase transition in [phases-and-transitions](schema/phases-and-transitions.md#transitions). Reads Clerk-produced surfaces. Never computes them.

## Pole Authority

Poles propose, revise own Propositions during DELIBERATING. No ratification, no withdrawal, no call to designer-authority entry in [procedure-actor map](schema/actors.md#procedure-actor-map).

## Clerk Authority

Clerk = deterministic script. Runs [Lint Batch](schema/procedures.md#lint-batch). Enforces [FK rules](schema/integrity-rules.md#fk-rules) and [session-close gate](schema/integrity-rules.md#session-close-gate). No deliberative surface. Fires automatic on procedure triggers.

## Forbidden Surfaces

Sprint-specific overlay attaches only via convening message. General `design-committee` agent files, general SKILL.md, output-format field labels = forbidden attach surfaces.

## Convening-Message Discipline

Inter-agent prompts follow [actors](schema/actors.md#convening-message-discipline). Per designer override: all sprint files use caveman ultra.
